# The-Walking-Dead-Ends-RL-Locomotion
A TD3 agent that learns bipedal locomotion from scratch in a Box2D BipedalWalker variant. It averages 226 reward over its final 100 easy-mode episodes and reaches a median of 207 on hardcore terrain, using n-step returns, action smoothing and an episode-length curriculum, with ablations documented in an accompanying paper.
